# EcoSim

Симуляция эволюции в браузере. Травоядные едят траву, хищники едят травоядных,
а потомки наследуют гены родителей с мутациями. Поведение никто не программирует
напрямую: гонка вооружений, циклы «хищник — жертва» и вымирания возникают сами.

## Запуск

```bash
npm install
npm run dev
```

## Что есть

- 🐇 **Травоядные**, 🐗 **всеядные** и 🦊 **хищники** со своей пищевой цепочкой.
- 🧠 **Два режима мозга**: поведение по правилам или **нейросеть**, веса которой — тоже гены.
  Её никто не обучает: случайные мозги мутируют, а отбор оставляет тех, кто выжил.
  У выбранной особи видно схему её мозга и как он «думает» в реальном времени.
- 🌳 **Родословная**: цепочка предков с генами, живые потомки подсвечены на карте золотом.
- 📈 Графики численности и **эволюции каждого гена** по видам.
- 🌸☀️🍂❄️ **Сезоны**: зимой трава почти не растёт, а существа мёрзнут. Есть **озёра**.
- ☄️ **Катастрофы**: метеорит, засуха, эпидемия. Всё попадает в **летопись**.

## Как устроено

- `src/genes.ts` — гены (скорость, зрение, размер, забота о потомстве, цвет, мозг) и мутации.
- `src/brain.ts` — нейросеть 9 → 6 → 2: ощущения на входе, поворот и «газ» на выходе.
- `src/world.ts` — мир: трава, существа, энергия, охота, размножение.
- `src/render.ts` — отрисовка на Canvas и график популяций.
- `src/main.ts` — UI: панель, инструменты, инспектор.

Каждый ген — компромисс: быстрым нужны мышцы, а их содержание стоит энергии;
хорошее зрение тоже «ест» энергию; крупное тело трудно поймать, но его дорого кормить.

## Управление

- 🔍 клик по существу — инспектор с его генами
- 🌱 кисть — посадить траву
- 🐇 / 🐗 / 🦊 — добавить существо
- ☄️ — уронить метеорит
- `Esc` — снять выделение
- `Пробел` — пауза
